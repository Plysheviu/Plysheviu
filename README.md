## Мої проєкти

### 2D RPG Game
*Повноцінна гра в жанрі RPG (Дипломний проєкт)*
* **Технології:** Unity, C#
* **Особливості та реалізовані механіки:**
  * **Побудова світу:** Створення багаторівневих локацій за допомогою `TileMap`, налаштування динамічного 2D-освітлення та реалізація механіки зміни дня і ночі.
  * **Навігація:** Запікання карт для коректного переміщення та розрахунку шляху.
  * **Анімації:** Створення та налаштування плавних анімацій для головного героя, ворогів та інтерактивних об'єктів оточення.
  * **Рольова система:** Розроблено систему прогресії персонажа (набір досвіду, підвищення рівня / Level Up), а також реалізовано систему навичок (скілів) для використання під час ігрового процесу.

### Monster Farm
*Вебплатформа для колекціонування та розведення монстрів*
* **Технології:** C#, ASP.NET (MVC), AJAX, JavaScript, HTML5/CSS3, Microsoft Azure
* **Особливості:** * Повноцінний вебдодаток, побудований на архітектурі MVC із використанням C# контролерів для обробки бізнес-логіки.
  * Інтегровано AJAX для асинхронних запитів, що забезпечує динамічне оновлення елементів сторінок без повного перезавантаження.
  * Реалізовано механіки колекціонування, систему інвентарю користувача та внутрішньоігровий маркетплейс.
  * Налаштовано та успішно розгорнуто (деплой) у хмарній інфраструктурі Microsoft Azure.
